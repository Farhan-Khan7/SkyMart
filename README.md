## ⚙️ Installation

Clone the repository

```bash
git clone <your-repository-url>
```

Go to the project folder

```bash
cd SkyMart-main
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
